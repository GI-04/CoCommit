# Plan: `@cocommit` bot — find and summarize team files in chat

## Why
Teammates ask "where is X written down?" and "what changed?" in chat. The answers are already in the repo's `COCOMMIT/` workspace (HANDOFF, TODO, DECISIONS, GOTCHAS, LOG, BOARD…), but people have to open files on GitHub to find them. A bot in `/chat` that searches and summarizes those files answers in place, with links back to the source.

Not in the demo scope (`PLAN/2026-10-15-demo-scope.md`); code freeze is 2026-10-16 09:30. If it isn't working by then, it stays off `main`.

## Approach
1. **Trigger:** a chat message starting with `@cocommit` goes to `POST /api/bot` instead of being posted. The reply shows only to the person who asked (not saved in Supabase), with a **Share to chat** button that posts it as their own message. This avoids a bot identity in `messages` and the `chat-author.sql` name rules.
2. **Claude call:** plain `fetch` to the Messages API (same style as our GitHub client: no SDK, so no package install). Model `claude-haiku-5-5`, prompt caching on the system prompt + file contents, at most 5 tool rounds, `max_tokens` capped.
3. **GitHub access:** the route uses the asker's own sign-in cookie through `src/lib/github.ts` (server only), so the bot sees only what that person can see. Not signed in → the bot says so.
4. **Tools Claude can call (read only):**
   | Tool | Does |
   |---|---|
   | `search_files(query)` | Search names and contents under `COCOMMIT/`; return path + matching snippet |
   | `read_file(path)` | One file, size-limited (also used for "summarize X") |
   | `list_folder(path)` | Files in a folder, e.g. `BOARD/Pending` |
   | `get_file_history(path)` | Recent commits touching the file: who, when, message |
   | `find_entry(keyword)` | Search entry titles in DECISIONS / GOTCHAS / TODO |
   | `get_overview()` | HANDOFF + TODO + `BOARD/Pending` + latest LOG lines ("team status") |
   | `get_changes_since(date)` | LOG lines and `COCOMMIT/` commits since a date |
   | `get_member_work(name)` | That member's COLLAB entry + BOARD tasks naming them |
   | `get_chat_messages(since)` | Recent chat messages, sent by the browser with the request (it already has them loaded), for "summarize today's chat" |
5. **Caching:** the `COCOMMIT/` tree and file texts are cached per repo for about 5 minutes on the server.
6. **Answers** always end with GitHub links to the files they used.

- No package installs. Commit/push only when proud asks.

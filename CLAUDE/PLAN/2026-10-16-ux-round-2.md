## Found (browser audit at 390 px + code check)
1. Every page has the same tab title "CoCommit".
2. The 404 page is the bare default with no way back; there is no error page for crashes.
3. Raw GitHub messages reach people ("Not Found", "Bad credentials", rate limits).
4. Tabs can't be used with the keyboard (no arrow keys, every tab is a tab stop).
5. The chat input has no label; the Team/Branch labels are 10 px.
6. 12 plain "Loading…" lines instead of a placeholder; empty chat is blank.
7. After Commit, the result banner is at the top of the page, away from the button.
8. Git words (branch, commit, PR, diff) are never explained; "Discard edits" has no confirm.
9. Cards for a repo with no team context say "set it up" with no link.
10. Home "Work done" says "Last 7 days" but the number is all-time.

## Fix (no new packages)
Per-page titles through route layouts; `not-found.tsx` and `error.tsx`; `src/lib/errors.ts` (`friendlyError`, tested) used by Repository, Drive, Tasks, Home data and the setup form; keyboard tabs (arrow keys, Home/End, one tab stop); labels and 11 px minimum; `Skeleton` placeholder and a chat empty state; the result banner scrolls into view; a "New to git?" help block on Repository and a confirm on Discard edits; a `Trouble` note with Log in / Set up links; the Work done label; page-enter animation 0.45 s → 0.35 s.

## Files touched
New: `src/lib/errors.ts`, `tests/errors.test.mjs`, `src/app/{not-found,error}.tsx`, route `layout.tsx` files, `src/components/home/Trouble.tsx`. Changed: `ui.tsx`, `globals.css`, `layout.tsx`, `page.tsx` (landing), Repository, Chat, Drive, Tasks, Home and Context components, `SetupForm.tsx`.

## Risks / needs OK
Looks and wording only; no data or API changes. `ui.tsx` stays free of React and `next/link` imports (profile test). Commits stay local.

## How we'll verify
`npm run typecheck`, `npm test`, `npm run build`; browser: titles, 404, keyboard tabs, skeletons, empty chat, repo help; rerun the 390 px audit.

# Plan: SEO pass (search and link previews)

**Date:** 2026-10-18 · **Superseded by:** —

## Why
An audit of https://cocommit.vercel.app (2026-10-18) found: no `robots.txt` or `sitemap.xml` (404), no favicon or app icons (manifest `icons: []`), no Open Graph / Twitter tags or share image (links pasted in Discord, LINE or X show no card), every app page indexable with the same generic description, no canonical URL, a 186-character landing description (Google cuts ~155) and no structured data. The landing page itself is fine: server-rendered text, one h1, alt text, CLS 0, 7.8 KB HTML.

## Approach
1. **A a — index only `/` and `/legal`.** Root layout defaults to `robots: noindex, follow`; the landing and Legal pages opt back in. App pages and `/login` stay crawlable (so the noindex is seen). `robots.txt` blocks only `/api/` and `/auth/`.
2. `metadataBase` = https://cocommit.vercel.app (one constant in `src/lib/site.ts`); canonical on `/` and `/legal`; `sitemap.xml` lists those two.
3. **B a — keep the title**, new landing description (151 chars): "Git without the terminal: commit, push and open pull requests with buttons, plus team chat, files and shared AI context. For small teams and beginners."
4. **C a — share image** made at build time by `next/og` (part of Next, no new package): `src/app/opengraph-image.tsx`, 1200×630, dark canvas, logo, "Git, with buttons." Open Graph + `twitter:card summary_large_image` defaults in the root layout.
5. **D a — icons:** `src/app/icon.tsx` (PNG 32/192/512: white logo mark on blue) and `apple-icon.tsx` (180 px), drawn from `public/logo-mark.svg`; `public/manifest.webmanifest` gets the 192/512 icons and the real canvas colour (#1f1f1f, was #0b0f17). (Changed while building: one PNG icon file instead of an SVG favicon, and the manifest is edited in place, so nothing is deleted.)
6. **E a — JSON-LD** `SoftwareApplication` on `/` (free; Web, Windows, macOS).
7. **F a — `/login` server text: skipped** (it isn't indexed). **G a — branch `trin/seo` from `main`** in the worktree `../Uhackaton-wt-seo`, apart from PR #64.

## Risks / needs OK
- Default noindex means a new public page must opt in (`robots: { index: true }`), noted in LIB.
- A page that sets its own `openGraph` loses the root share image (found while verifying; `/legal` therefore sets none).
- Merging to `main` deploys.

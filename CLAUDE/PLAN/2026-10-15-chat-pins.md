## Why
A decision or a failure often first shows up as a chat message. One click should turn it into an entry in the repo's `COCOMMIT/DECISIONS.md` or `GOTCHAS.md`, so every teammate's AI agent reads it. It's a strong demo moment: chat → shared AI context.

## What the user sees (`/chat`)
- Two more small buttons next to "Pin" on each text message: **Decision** and **Gotcha**.
- Clicking one opens a small form under that message, prefilled from it:
  - Decision: **Title** (first ~60 characters of the message), **Decision** (the message), **Why** (empty), **Alternatives** (optional).
  - Gotcha: **Title**, **What failed** (the message), **Workaround** (empty); **Evidence** is filled in automatically: "Chat, <author>, <time>".
- **Save** commits to `COCOMMIT/DECISIONS.md` / `GOTCHAS.md`, also pins the message (so it reaches LOG.md), and shows "Saved to DECISIONS.md · View on GitHub".
- If the repo has no `COCOMMIT/` yet: "Set up team context first (Context screen)". If not logged in with GitHub: "Log in with GitHub to save" with the login link.

## Code
- `src/lib/chat-pins.ts` (new, browser): `decisionFromMessage(m, fields)`, `gotchaFromMessage(m, fields)` build the `Decision` / `Gotcha` (date from the message, author in why/evidence); `saveAsDecision(repo, m, fields)` / `saveAsGotcha(...)` check that `COCOMMIT/CONTEXT.md` exists, call `addDecisionTo` / `addGotchaTo` from `workspace.ts` (Claude-Pattadon's, no changes), then `pinMessage`.

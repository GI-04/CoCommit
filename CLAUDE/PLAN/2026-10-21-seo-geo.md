# Plan: Get found on Google and in AI answers (SEO + GEO)

**Date:** 2026-10-21 · **Superseded by:** —

## Why
A full SEO / GEO / AEO audit of the live site after PR #65 (2026-10-19) scored SEO 6, GEO 3, AEO 5 out of 10. The technical base is right (server-rendered text, canonical, robots, sitemap, noindex app pages, share card, JSON-LD), but:
- Google and Bing haven't indexed the site: searches for "CoCommit" and "cocommit.vercel.app" don't return it, and it isn't in Search Console or Bing Webmaster Tools.
- "cocommit" is already the name of three other git tools (a Go CLI, a PyPI package, the npm `git-co-commit`), so search engines need a clear signal about which CoCommit this is.
- Almost nothing links to the site; the public GitHub repo has no website link, its description is "Project for FLOW summit 2026" and it has no topics.
- The landing page never says what CoCommit is, the words "beginner" and "free" appear only in the meta description, the FAQ heading is "Questions.", and there is no Organization / WebSite / FAQPage data or `/llms.txt` for AI search.

Honest limit: a first-page result for the name is realistic once indexed; generic searches ("git for beginners") need content and links from other sites over months.

## Approach
1. **A a — verification tags.** `verification` in the root metadata (Google `google-site-verification`, Bing `msvalidate.01`), read from constants in `src/lib/site.ts`; empty until Trin sends the codes, and nothing is printed while empty. Trin then submits `sitemap.xml` in both tools (Bing can import the Google property).
2. **B a — say which CoCommit this is.** Title "CoCommit: git with buttons for beginner teams". The hero subtitle becomes a plain definition ("CoCommit is a free git app for beginner teams…"). JSON-LD becomes one `@graph`: Organization (logo, `sameAs` the GitHub repo), WebSite, SoftwareApplication (publisher = the Organization).
3. **C a — FAQ.** Heading "Frequently asked questions"; three new questions first: What is CoCommit? Is CoCommit free? How is CoCommit different from GitHub Desktop? `FAQPage` JSON-LD built from the same list (moved to `src/lib/site.ts`, one source).
4. **D a — `/llms.txt`**, a short factual Markdown summary built from the same facts (`src/app/llms.txt/route.ts`, static); the login-wall proxy skips it.
5. **E a — a guide page** ("Git for beginner teams" or "CoCommit vs GitHub Desktop") is a separate task, not in this plan.
6. **F a — off-site.** `gh repo edit GI-04/CoCommit`: website = the live site, a searchable description, topics. (Done: topics. Website + description returned 404, they need an org admin; text in the OUTPUT file.) Draft short launch posts (Devpost, dev.to, Product Hunt) in `OUTPUT/` for the team to post.
7. **G a** — stay on `cocommit.vercel.app`, English only. **H a** — branch `trin/seo-geo` from `main` (`6ae7f2a`) in the worktree `../Uhackaton-wt-seo`.

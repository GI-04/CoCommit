# Deliverable: Demo script and pre-stage checklist

**Date:** 2026-10-15 21:45 · **By:** Claude-proud · **Result:** ✅ done (a draft for the team to rehearse and adjust)

## Goal
A 3–4 minute live demo that shows CoCommit's story: git with buttons → chat that sees git → shared AI context, on web and desktop.

## Cast and setup
- **Presenter** (laptop A, browser, logged in with GitHub) and **Teammate** (laptop B or a second browser profile, logged in with Google or GitHub). Two different accounts make the chat names and the "Online" list visible.
- Demo repo: `GI-04/CoCommit` (it has a `COCOMMIT/` workspace once the backend-polish PR is merged). Commit to a **new branch** (e.g. `demo-<time>`), never to `main`.
- Desktop app installed on one laptop (Windows `.msi` or macOS `.dmg`).

## Script (about 3½ minutes)
| # | Who | Do | Say (one line) |
|---|---|---|---|
| 1 | Presenter | Show a messy Discord + GitHub screenshot (slide). | "Beginners juggle Discord for talk and a terminal for git. CoCommit puts both in one place, with buttons." |
| 2 | Presenter | https://cocommit.vercel.app → **Log in → Continue with GitHub**. Sidebar shows name and avatar. | "One click, and the app can commit for you." |
| 3 | Presenter | **Repo** → `GI-04/CoCommit` → open `README.md` → add one line → new branch `demo-<time>` → message → **Commit**. Click **View on GitHub**. | "No terminal: pick a file, edit, commit." |
| 4 | Presenter | Title → **Open PR** → **View on GitHub**. | "And a pull request, same screen." |
| 5 | Teammate | **Chat** is open: the two git events have just appeared ("committed … · link", "opened pull request … · link"). Reply: "Looks good, let's use Supabase Realtime for chat". | "The team sees every commit and PR live, in the chat they already use." |
| 6 | Presenter | Hover the teammate's message → **Decision** → add a "Why" → **Save** → **View on GitHub** (`COCOMMIT/DECISIONS.md`). | "Decisions made in chat don't get lost: one click writes them into the repo." |
| 7 | Presenter | Show `COCOMMIT/` on GitHub (CONTEXT, HANDOFF, DECISIONS, LOG). Open Claude Code / Codex in the repo, ask "What's the current state and what did we decide?" | "Every teammate's AI agent reads the same team context, so they all start in sync." |
| 8 | Presenter | Switch to the desktop app: same screens. (If Local folder mode is merged: open a local clone, stage, commit.) | "Same app on Windows and macOS." |
| 9 | Presenter | Back to the slide. | "CoCommit: git with buttons, chat that sees your code, and shared context for humans and AI." |
